# BuildMe Website

Website for **BuildMe**, a company offering social media management and digital skills training.

**Tagline:** Your brand online, built to last.

## Files
- `index.html` : the whole site (HTML, CSS and JavaScript in one file)
- `assets/` : logos (PNG and SVG)

## Run locally
Open `index.html` in a browser.

## Host for free with GitHub Pages
1. Push this repository to GitHub.
2. Go to Settings > Pages.
3. Under Source choose "Deploy from a branch", select `main` and `/ (root)`, then Save.

## Note
The admin panel (managing gallery images, client logos and team photos) only works while the page is opened
inside claude.ai by its owner. On GitHub Pages the site displays normally but the admin panel stays hidden.
To edit content there, change `index.html` directly.
